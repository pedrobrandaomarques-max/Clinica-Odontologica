# 🦷 Odonto Elias

### Site institucional de clínica odontológica | HTML5 e CSS3

O **Odonto Elias** é um projeto de desenvolvimento web que apresenta a estrutura de um site institucional para uma clínica odontológica. A proposta é reunir informações sobre tratamentos, equipe e contato em uma interface organizada, com navegação entre páginas e estilos adaptados a diferentes tamanhos de tela.

> **Contexto:** projeto de aprendizagem desenvolvido durante o curso básico de **HTML e CSS no SENAC**. Esta versão preserva características dos meus primeiros estudos: há textos de exemplo e o formulário ainda não possui integração para envio de mensagens.

## 🎓 Origem do projeto

O **Odonto Elias** foi um dos meus primeiros projetos de desenvolvimento web, criado durante o curso básico de **HTML e CSS no SENAC**.

O desenvolvimento do site foi uma oportunidade de aplicar, na prática, conceitos iniciais de estruturação de páginas, estilização, organização visual e navegação. Esse trabalho marcou uma etapa importante da minha trajetória de aprendizado.

Por ser um projeto inicial, mantive sua proposta original como registro da minha evolução na programação.

## 🎯 Objetivo

Praticar a criação de páginas web com **HTML5 e CSS3**, utilizando organização de conteúdo, navegação, elementos visuais, formulários e técnicas básicas de responsividade.

## 📄 Páginas do site

| Página | Conteúdo |
| --- | --- |
| **Início** (`index.html`) | Apresentação da clínica, cards de tratamentos odontológicos e destaque para harmonização facial. |
| **Quem Somos** (`quemsomos.html`) | Área de apresentação dos integrantes da equipe. |
| **Serviços** (`servicos.html`) | Lista de especialidades e seção de apresentação do tratamento com alinhadores transparentes. |
| **Contato** (`contato.html`) | Formulário visual com campos de identificação, telefone, e-mail, data de nascimento e mensagem. |

### 🪥 Tratamentos apresentados

O conteúdo do site menciona **implantes, clareamento dental, cirurgias, próteses, harmonização facial, Invisalign®, dentes do siso e odontopediatria**. Esses itens são apresentados como informações do site, não como funcionalidades de agendamento.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura das páginas, navegação e formulário.
- **CSS3:** cores, tipografia, espaçamento, cards e organização visual.
- **Flexbox:** disposição dos menus e das seções.
- **Media queries:** ajustes de layout para telas com largura de até 768 px.
